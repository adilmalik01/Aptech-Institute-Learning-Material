# Habitat Institute Learning Material

Teaching and learning material for students at **Habitat Institute**.

This repository is the organized classroom hub. Original batch repositories are still on GitHub and were not deleted.

## Who this is for

- **Students** — lesson folders by topic, plus assignments and practice sites
- **Instructors** — one place to share class work across batches
- **Recruiters** — structured teaching across frontend, backend, and APIs

## Topics

| Folder | What you will find |
| --- | --- |
| `HTML/` | Markup lessons (Batch5to7, Batch3to5, Batch11to1) |
| `CSS/` | Styling lessons (Batch5to7, Batch3to5) |
| `JavaScript/` | Fundamentals through DOM/API work, plus a beginner guide |
| `Bootstrap/` | Component and layout practice |
| `Tailwind/` | Utility-first CSS lessons |
| `jQuery/` | jQuery class exercises |
| `Node.js/` | Pointer to Express lessons (Node was taught with Express) |
| `Express.js/` | Numbered server lessons 1-6 |
| `REST-APIs/` | Fetch/API lessons, weather API, Postman collection |
| `React/` | Component lessons (hello-world, props) |
| `PHP/` | PHP classes, projects, and session outline PDFs |
| `Laravel/` | Class Laravel app (no vendor, no secrets; use `.env.example`) |
| `Assignments/` | Instagram clone, blogs, portfolio, responsive site |
| `Practice/` | Full practice websites from class |

See `SOURCES.md` for the original repositories.

## How to use

1. Open the folder for your current topic.
2. HTML, CSS, Bootstrap, and most JavaScript lessons open in a browser.
3. Node/Express lessons need Node.js installed (`npm install` then `npm start` or `npm run dev`).
4. PHP lessons need PHP or XAMPP.
5. Laravel: copy `.env.example` to `.env`, then `composer install` (do not commit `.env`).
