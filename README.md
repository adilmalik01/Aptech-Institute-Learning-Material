# Habitat Institute Learning Material

Teaching and learning material created and maintained for students at **Habitat Institute**.

This repository is the organized classroom hub. Original batch repositories are still on GitHub and were not deleted.

## Who this is for

- **Students** — lesson folders by topic, with assignments and practice work
- **Recruiters** — evidence of structured teaching across frontend, backend, and APIs

## Topics

| Folder | Contents |
| --- | --- |
| HTML | Markup lessons from class batches |
| CSS | Styling lessons |
| JavaScript | Fundamentals through APIs, including jQuery where taught |
| Bootstrap | Layout and component practice |
| Tailwind | Utility-first CSS lessons |
| Node.js / Express.js | Server lessons |
| REST-APIs | Fetch, HTTP methods, Postman collection |
| React | Component lessons |
| PHP | Class PHP projects and session outlines |
| Laravel | Class Laravel project (no vendor / secrets) |
| Assignments / Practice | Student-facing builds |

See `SOURCES.md` for the original repositories this material was copied from.

## How to use

Open the topic folder for your current class. Most HTML/CSS/JS lessons open directly in a browser. Node and PHP lessons need a local runtime (Node.js or XAMPP/PHP).
